# AGENTS.md

## Project Setup
This repo is a web application for mindmaps using Vue.js and Vite.
- Install dependencies: `npm install`

## Development Commands
- Run development server: `npm run dev` (runs Vite dev server)
- Build for production: `npm run build` (runs Vite build to `dist/`)
- Lint: `npm run lint` (if ESLint configured)
- Test: `npm test` (if testing framework configured)

## Project Structure
- `src/` – Application source code (HTML, CSS, JS/TS)
- `dist/` – Production build output (generated by Vite)
- `package.json` – npm scripts and dependencies

## Technology Choices
- Language: JavaScript (Vue 3)
- UI: Vue 3 framework
- Bundler: Vite
- Mindmap rendering: Vue Flow

## Notes
- Ensure any build artifacts (`dist/`, `.vite/`) are excluded from version control.
- The app entrypoint is `index.html` (bundled into `dist/index.html`) which loads `src/main.js`.
