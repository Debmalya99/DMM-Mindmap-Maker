## DMM Mindmap Maker

![showcase-screenshot](/showcase-assets/dev-sheet-screenshot-3Oct26.png)

DMM is a free and open-source tool to create mindmaps and visualize your ideas. It is built atop Vue JS and VueFlow libraries and it has the following **features**:
1. Saves your mindmaps to your PC in an easy to access json file (.dmm.json) (& Loads them as well for use)
1. Supports a lot of convenient hotkeys to speed up your workflow.

### Installation
- The app is already hosted at my website here: [Link](https://debmalya99.github.io/app-mindmap/), but if you want to host it locally, here is how you can do that:

First clone the repository to your local machine, then once in your cloned directory
~~~bash
npm install #installs all the dependencies
npm run dev #starts a development server, likely at the port 3000
npm run build #builds the app into the dist/ folder.
~~~
